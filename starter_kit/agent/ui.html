    入门教程 · 从零看懂量子计算

    一、普通电脑是怎么算的？

    先从你已经熟悉的东西说起。

    你现在用的电脑，把所有信息都存成一长串 0 和 1。每一个 0 或 1 叫一个「比特」。照片、音乐、这段文字，最后都是 0 和 1。

    关键在于：一个普通比特，任何时刻只能是 0 或者 1，二选一。就像一枚放在桌上的硬币，要么正面朝上，要么反面朝上。

    如果要试遍 3 个比特的所有组合（000、001、010……111 共 8 种），普通电脑只能一种一种试，试 8 次。

    二、量子比特特别在哪？

    一句话：它可以「同时是 0 和 1」。

    想象把硬币立起来快速旋转。在它转的时候，你没法说它是正面还是反面——它处在两种可能的混合里。这种状态叫叠加。

    普通比特桌上的硬币：不是正面，就是反面。
    量子比特旋转中的硬币：两种可能同时存在，直到你伸手按住它。

    「伸手按住」就是测量。一测量，旋转停止，你只会看到一个确定的 0 或 1，叠加就消失了。

    所以 3 个量子比特可以同时承载 8 种组合。比特越多，这个数字翻倍得越快——50 个量子比特能同时表示的组合数，超过一千万亿种。

    这就是量子计算被看好的原因：某些问题（药物分子模拟、材料设计、密码分析）用普通电脑要算几万年，量子计算机原理上快得多。

    三、还有一个关键：纠缠

    两个量子比特可以「绑定」在一起。

    把两枚旋转的硬币纠缠起来之后，它们会变成这样：你按住其中一枚看到正面，另一枚必定也是正面；你看到反面，另一枚必定也是反面。

    但在你去看之前，谁也不知道会是哪一面——它们各自都是 50/50。神奇的是关联性：结果永远一致，从不出现一正一反。

    测 1000 次，三个纠缠的量子比特会得到：

  000  ████████████████████  约 500 次
  111  ████████████████████  约 500 次

  001、010、101……  一次都不会出现

    四、为什么要「写」量子程序？

    因为量子计算机不会自己知道你想算什么。

    量子比特本身只是一堆会旋转的硬币。要让它们算出有用的东西，你得按顺序告诉它每一步做什么：先让第 1 枚转起来，再把第 2 枚和它绑定……

    这份「操作说明书」就是量子程序，也叫量子电路。它和菜谱很像：食材是量子比特，步骤是一个个量子门，最后测量就是尝一口看做成了什么。

    • H 门（阿达马门）——让一个量子比特开始「旋转」，进入叠加
    • CX 门（受控非门）——把两个量子比特绑定起来，产生纠缠
    • 测量——按住硬币，读出最终的 0 或 1
    常用的门就十几个。你不需要背它们——这个工具会根据你的大白话自动挑选。

    五、量子程序长什么样？

    下面这段就是完整的「三比特纠缠」程序。

    OPENQASM 2.0;          ← 用的是哪种语言
include "qelib1.inc";  ← 载入标准门库
qreg q[3];             ← 准备 3 个量子比特
creg c[3];             ← 准备 3 个格子放测量结果
h q[0];                ← 让第 1 个转起来（叠加）
cx q[0],q[1];          ← 把第 2 个和第 1 个绑定（纠缠）
cx q[0],q[2];          ← 把第 3 个也绑定进来
measure q -> c;        ← 全部测量，结果存进格子

    这种写法叫 OpenQASM，是量子领域通用的「汇编语言」。八行，没有循环，没有函数，从上往下依次执行。

    好消息是：你不用自己写。在上面的输入框里说一句「让三个量子比特纠缠在一起」，助手会生成这段代码、跑一遍验证它是否正确，再把电路图和结果解释给你听。
